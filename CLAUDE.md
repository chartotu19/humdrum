# CLAUDE.md

## Project Overview

**Humdrum** is a lightweight frontend boilerplate for building web applications with React. It provides a pre-configured build pipeline using Grunt and Webpack with ES6 (ES2015) transpilation via Babel. The project uses Bootstrap for styling.

- **License**: MIT
- **Author**: chartotu19

## Tech Stack

| Layer         | Technology                        |
|---------------|-----------------------------------|
| UI Framework  | React 0.14, React DOM 0.14        |
| CSS Framework | Bootstrap 3.3.5 (via Bower)       |
| Module Bundler| Webpack 1.12                      |
| Task Runner   | Grunt 0.4                         |
| Transpiler    | Babel 6 (presets: es2015, react, stage-0) |
| Package Mgmt  | npm (JS tooling), Bower (frontend assets) |

```
│       ├── copy.js         # Copies index.html to public/
│       ├── watch.js        # File watcher with LiveReload (port 1337)
│       └── webpack.js      # Webpack bundler config

├── grunt-helper.js         # Grunt utility functions
├── package.json            # npm dependencies and scripts
├── bower.json              # Bower dependencies (Bootstrap)

    ├── index.html
    └── js/bundle.js
```

## Getting Started

```bash
# Install dependencies
npm install
bower install

# Start development server (clean, build, serve, watch)
grunt
```

The default Grunt task runs: `clean:dev` -> `webpack` -> `copy` -> `connect` -> `watch`

- Dev server runs at **http://localhost:3434**
- LiveReload is on port **1337**

## Build Pipeline

1. **clean:dev** - Removes the `public/` directory
2. **webpack** - Bundles `src/index.js` through Babel (ES6/JSX -> ES5) into `public/js/bundle.js`
3. **copy** - Copies `src/index.html` to `public/index.html`
4. **connect** - Starts a static file server from `public/`
5. **watch** - Watches `src/` for changes and rebuilds automatically

## Code Conventions

- **ES6 modules**: Use `import`/`export` syntax (transpiled by Babel)
- **React components**: Use ES6 class syntax extending `React.Component`
- **Component files**: PascalCase filenames (e.g., `HeroUnit.js`)
- **Components directory**: Place React components in `src/components/`
- **Entry point**: `src/index.js` handles top-level DOM mounting via `ReactDOM.render()`
- **Indentation**: Tabs in source files

## Important Notes

- The `public/` directory is gitignored — it is generated by the build
- Bower installs frontend assets to `public/assets/` (configured in `.bowerrc`)
- The package.json description references Angular, but the codebase has migrated to React
- Source maps are enabled in the Webpack config (`devtools: 'source-map'`)
- Webpack resolves modules from `node_modules/` and processes `.js`/`.jsx` files through Babel
